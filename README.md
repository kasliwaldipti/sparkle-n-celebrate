# Sparkle N' Celebrate

An online jewellery store for Sparkle N' Celebrate. Customers can browse the catalogue, pay with Razorpay, and follow their orders, with an AI assistant that sends shipping updates and answers order questions. Store admins manage products, photos, stock and orders from a dashboard.

## Tech stack

- **Framework:** Next.js 16 (App Router), React 19, TypeScript
- **Styling:** Tailwind CSS 4, shadcn/ui
- **Database:** Neon Postgres with Prisma 7
- **Auth:** Auth.js v5
- **Payments:** Razorpay (INR)
- **Images:** Cloudinary
- **Email and SMS:** Resend, Twilio
- **Background jobs:** Inngest
- **Shipment tracking:** AfterShip
- **AI order agent:** Anthropic Claude
- **Admin dashboard:** Recharts, TanStack Table
- **Validation and testing:** Zod, Vitest
- **Hosting:** cPanel (Node.js via Passenger), deployed with GitHub Actions
